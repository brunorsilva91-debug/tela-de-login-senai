# Next.js + Supabase Auth Project

Este é um template básico de autenticação contendo uma tela de login e cadastro integrada ao Supabase utilizando SSR.

## Passos para rodar o projeto:

1. Extraia o conteúdo deste arquivo zip na pasta do seu projeto.
2. Certifique-se de configurar o arquivo `.env.local` com as suas credenciais obtidas no painel do Supabase.
3. Instale as dependências:
   ```bash
   npm install
   ```
4. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
